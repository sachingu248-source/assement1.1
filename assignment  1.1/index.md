(Explanatory Paragraph)

When we type a URL (Uniform Resource Locator) such as www.google.com into a web browser, the browser acts as a client and sends an HTTP (HyperText Transfer Protocol) or HTTPS (HyperText Transfer Protocol Secure) request to a web server over the internet. The server receives the request, processes it, and if required, retrieves data from a database. The server then sends a response containing web files such as HTML, CSS, JavaScript, images, or database-generated content back to the browser. The browser interprets this information and displays the webpage on the screen. This communication between the browser and server is called the request-response cycle. A static website shows fixed content that remains the same for all users unless manually updated, whereas a dynamic website generates content dynamically using databases and server-side processing, allowing personalized and frequently changing information. By opening Chrome DevTools (F12) and checking the Network tab, we can observe all requests and responses exchanged while a website loads.
